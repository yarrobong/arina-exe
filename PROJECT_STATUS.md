# Арина.exe — статус первой версии

## Уже сделано

- Mobile-first оболочка до 480 px.
- Чёрно-розово-серебристая Y2K дизайн-система.
- Первый экран с горизонтальным фото-слайдером.
- Верхнее якорное меню.
- Реальный контент из интервью по детству, школе и УрФУ.
- Scroll-storytelling карта на MapLibre: карта sticky, главы географии меняются при прокрутке; после добавления координат камера автоматически летит к точке.
- Эволюция Arina.exe в формате changelog.
- Карточки друзей.
- История знакомства с Яриком.
- «Арина в цифрах» и мемные показатели.
- Инвентарь.
- Раскрываемый «Компромат».
- Будущее: версия Арины + короткая версия Ярика.
- Нижний музыкальный плеер, подготовленный для будущих треков.
- Y2K-заглушки вместо отсутствующих фотографий.
- Скрипт Sharp для конвертации исходных фото в WebP.

## Следующий проход

1. Подставить первые 10–15 настоящих фотографий.
2. Уточнить координаты ключевых мест и заполнить places.ts.
3. Сделать полноценный fullscreen photo viewer со свайпом между снимками.
4. Добавить конкретные песни периодов.
5. Доработать анимации переходов между жизненными эпохами после появления реальных медиа.
6. Провести performance-pass на iPhone.
